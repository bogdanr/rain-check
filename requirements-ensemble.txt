# Dependencies for the external ensemble leg (Tasks 20a/20c/20d).
#
# Deliberately a SEPARATE file from requirements-site.txt, for the same reason
# that file exists: the published page is rebuilt in CI from committed parquet
# and PNG artefacts and must never need any of this. Nothing here is imported
# by report.py or by anything run_all.sh executes; installing it is only
# required to re-collect from NOAA, not to reproduce the paper's numbers from
# the tables in data/processed/.
#
# Consumed by:
#   src/gefs_archive.py        STAC resolution + archive access layer
#   src/collect_gefs.py        tile-grouped extraction -> data/raw/gefs/
#   src/ensemble_pop.py        member-derived PoP (needs only pandas/numpy)
#   src/validate_gefs_grib.py  raw-GRIB2 audit against s3://noaa-gefs-pds
#
# Versions are the ones the 2026-09-15 feasibility investigation verified end
# to end against s3://dynamical-noaa-gefs. Pinned exactly, because the store is
# Zarr v3 + Icechunk: the format is young and a reader-version mismatch fails
# as a confusing decode error rather than a clean "unsupported version".

# -- analysis-ready Zarr archive (dynamical.org NOAA GEFS) -------------------
icechunk==2.2.0          # transactional Zarr store; opened anonymously,
                         # read-only, via Repository.open(s3_storage(...))
zarr==3.3.0              # v3 required: the store uses sharding + v3 codecs
xarray==2026.7.0         # labelled access to init_time/lead_time/member
numcodecs==0.16.5        # pulled in by zarr; pinned so the codec set is fixed

# -- raw GRIB2 provenance audit (src/validate_gefs_grib.py) -----------------
# Only needed to RE-RUN the audit. The audit's verdict is committed as
# data/processed/gefs_grib_validation.{parquet,json}, so a reader reproducing
# the paper does not need a GRIB stack at all. eccodes ships manylinux wheels
# with the ECMWF C library bundled, so this is a plain pip install with no
# system packages - the concern raised in the task brief did not materialise.
eccodes==2.48.0          # message decode; used directly, not via xarray
cfgrib==0.9.15.1         # not imported today, but the standard companion and
                         # the fallback if the audit ever needs full-field reads
