# Dependencies for rebuilding the published page from committed artefacts.
#
# This is deliberately *not* the full analysis environment. CI does not re-run
# the study: it reads the parquet tables in data/processed/ and the PNGs in
# figures/ committed alongside the code, and rebuilds dist/ from them. That
# keeps deploys fast and, more importantly, keeps them honest - a copy edit
# cannot silently change a published number, because nothing is recomputed.
#
# Versions are pinned because the build must be byte-reproducible; a float
# formatting change between pandas releases would otherwise surface as a
# spurious diff in the rendered tables.
